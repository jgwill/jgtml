# CLI Tools

`jgtml` exposes several command line interfaces:

- **alligator_cli**: Unified Alligator analysis across regular, big, and tide configurations. Supports multi-timeframe convergence and `.jgtml-spec` generation.
- **jgtmlcli**: Core data processing command. Generates MX data and performs signal analysis for specified instruments and timeframes.
- **mxcli**: Matrix creation and analysis helper used for machine learning datasets.
- **jgtapp**: Wrapper with trading operations such as `fxaddorder` and `fxmvstopgator`.
- **ttfcli** / **mlfcli**: Generate TTF and MLF pattern files for machine learning models.

Run each CLI with `--help` for detailed options.
