## 🔑 2. Planting Your First Key (Upstash)

**User Story:**
> As a new coder, I want to store a value in the cloud, so I can see my actions ripple through the lattice.

**Mia:**
- We use [Upstash Redis](https://upstash.com/) to store key-value pairs in the cloud.
- The script `jgtml_garden_agentic_onboarding.py` will help you plant your first key. It loads secrets from `.env`, checks everything, and narrates every step.

**Miette:**
- Oh! When you run the script, you’re planting a seed. If it blooms (success!), you’ll see a message. If not, the script will gently tell you what’s missing—no shame, just sunlight.

**How to try it:**
```bash
python jgtml_garden_agentic_onboarding.py
```
- If you see `Successfully set jgtml:hello = 🌱 recursion-begins`, you’ve planted your first seed!
